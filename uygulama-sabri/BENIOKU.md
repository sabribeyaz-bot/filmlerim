# Film Merkezi (Sabri)

Orijinal Film Merkezi 2.0.1 paketinin kendi kanalıma bağlanmış kopyası.

- Uygulama kimliği: `FilmSabri1.FilmMerkezi` (orijinal `FilmMerkez.FilmMerkezi` ile yan yana kurulabilir)
- Güncelleme kanalı: `https://raw.githubusercontent.com/sabribeyaz-bot/filmlerim/main/github-eklenti/201`
- Değişen dosyalar: yalnızca `bootstrap/config.js` (kanal adresi) ve `config.xml` (ad ve kimlik). İmzalı dosyalara dokunulmadı.

Kurulum: Tizen Studio → File → Import → General → Existing Projects into Workspace → bu klasör → Run As → Tizen Web Application.
