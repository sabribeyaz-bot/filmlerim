# Film Merkezi (Sabri) — WGT 2.0.3

Orijinal `uygulama/` (WGT 2.0.3) klasörünün kendi kanalıma bağlanmış kopyası.

- Uygulama kimliği: `FilmSabri1.FilmMerkezi` (orijinal Film Merkezi ile yan yana kurulur)
- Güncelleme kanalı: `https://raw.githubusercontent.com/sabribeyaz-bot/filmlerim/main/github-eklenti/201`
- Değişen dosyalar: `bootstrap/config.js` (kanal adresi), `config.xml` (ad ve kimlik), `bootstrap/boot.js` (sonuna eklenen kod: ilk açılışta bu depodaki iki depo listesini ekler; puhutv P002, NOW P003, Star TV P005 eklentilerini kurar).
- İmzalı dosyalara dokunulmadı.

Kurulum: Tizen Studio → File → Import → Existing Projects into Workspace → bu klasör → Run As → Tizen Web Application.
